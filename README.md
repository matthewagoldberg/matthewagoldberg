## 🤖 Robotics and Controls Experience

I spent six years in FIRST robotics, including four years in FIRST LEGO League and two years in FIRST Tech Challenge, and served as a **Programming Lead**.

My work focused on control theory, autonomous systems, embedded communication, telemetry, and custom software infrastructure. Competition restrictions prevented us from using certain existing approaches, so I developed a proprietary communication library that allowed the robot to host a server and interface with an external dashboard and compute system.

I also developed custom control systems and software for:

* Command handling
* Live data exchange
* Coordination between embedded hardware and external computing resources
* Autonomous behavior
* Telemetry and diagnostics
* Hardware and software integration

This work required designing around strict technical constraints, debugging software and hardware as a complete system, and building tools that did not already exist for our use case.
